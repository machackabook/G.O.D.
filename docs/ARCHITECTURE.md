# G.O.D. public architecture v5

```text
PUBLIC CHROME / MOBILE BROWSER
         |
  Standard Web APIs (permissions)
         |
      G.O.D. Gate  --> Local receipts --> Export
         |
  Optional Desktop Chrome Extension
      (manual install; read-only)
         |
  Future authenticated SYNAPSE gateway
      (private; not in this repository)
```

Gate stages: DISCOVER → OBSERVE → NORMALIZE → CLASSIFY → VERIFY → FINGERPRINT → LOOKUP_REMEDY → APPLY_REMEDY → REVERIFY.

`G.O.D.` regulates *declared browser capabilities* and records outcome as factual evidence. Its physics/electrical terminology is conceptual analogy; this public web runtime is not an electrical safety relay, a safety-critical trip circuit, a cryptographic KEM implementation, or a reliable detector of LLM hallucinations.

Cross-site collaboration must use per-origin authorization and explicit user consent. No private keys in JavaScript, flags toggling, hidden browser modifications, or silent extension installation.
