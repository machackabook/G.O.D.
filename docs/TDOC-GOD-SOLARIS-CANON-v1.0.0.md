## Canonical scene — user-specified

The canonical Sarafin/SolarisDragon version portrays **a dragon at a computer/workstation inside an expansive dark void filled with dynamic particles**. The dragon and computer must be spatially grounded in the scene; the work environment is the narrative focus, not merely an animated icon.

NON-CANONICAL SUBSTITUTES:

## Scene component contract

1. Background void: animated volumetric/star particles, parallax, actual measured render performance and adaptive graphics mode. Canvas 2D fallback if no WebGL2.
2. Dragon operator: authored source art/animation or original mesh, validated license and attribution, no silhouette or photo swapped without provenance.
3. Workstation: actual input/output state from the local browser application, not fictional CPU throughput or fake system logs.
4. UI: accessible layered panels, nested click-through route tree, cursor and keyboard support with reduced-motion option, controller navigation when supported.
5. Gate: user actions use real Web APIs only after browser permission; optional Chrome companion is never auto-installed; chrome://flags remains a user-operated setting.
6. Evidence: asset SHA-256, source filename, source owner/licensing evidence, rendering capture, device/browser matrix, frame timings, and actual interaction traces before "verified."
7. Security: no credentials, exact devices, private location, biometric signatures, secrets, or private backend telemetry in public static assets.
